# QC 协议（lite 档）

> lite 档的 QC 原则：**能算的绝不靠看，能拦的绝不靠记。**
> 代价是必须诚实标注「哪条判据我这轮没覆盖」——**没覆盖比误报更危险，误报至少会响。**

---

## 1. 一条命令跑完所有轴

```bash
python scripts/lite_gate.py                 # 自动分期 → qc/lite_gate.md
python scripts/lite_gate.py --tag v1        # 产物 qc/lite_gate_v1.md
python scripts/lite_gate.py --require-final # 强制成片期（缺 fin_frames 即失败）
```

**rc=1 即不通过。** 不要看输出里有没有"✗"，看退出码——因为**「未跑」也是一种失败**。

脚本存在的唯一理由：EXP-01 实测，C2 首版**跳过 `frame_metrics`** 就漏掉一个硬规则违反（换图元时 `glow` 忘传 → 220px 主角无光，`motion_check` 与 `selfcheck` 都不报）。
**失败模式不是「判据错」，是「有一根轴没跑」——而没跑的轴不会报错。** 所以四轴合并成一条命令 + 一个退出码，让"跳跑"在结构上不可能发生。

---

## 2. 四轴覆盖的物理量（互不重叠，缺一不可）

| 轴 | 命令 | 覆盖的物理量 | 门禁 |
|---|---|---|---|
| **1. 结构一致** | `selfcheck.py` | 帧覆盖空洞 · GlitchIn 白名单计数 · 画面字面量 vs 事实清单 · `[drift]` 分镜表与源一致 | rc 门禁 |
| **2. 空间冲突** | `zorder_audit.py --gate` | **层序倒置 Z1**（后入场被先入场实心块压住）· 同帧叠字 Z2 · **可审覆盖率** | rc 门禁 |
| **3. 动效密度** | `motion_check.py --frames` | 每镜头静止帧占比 · 最长静止段 · 真静/小面积动作分类 | 成片期 rc 门禁 |
| **4. 画面构成** | `frame_metrics.py --frames` | 最大物体尺度 · 主角区柔光 · 紫色碎片 · 背景碎屑 | **仅报告**（见下） |

**轴 4 为什么只报告不门禁**：它的「高」是**相对量**——C0 基线本身就有 1 条"空场"高标记（主角是"最大物体"单选取，双大物体镜头必然误报）。把它硬门禁会逼人改判据，判据一松就再也拦不住真的空场。**逐条并入 QC 人工裁定。**

**分期**

- **构建期（无 `fin_frames`）**：只能跑轴 1、2 → 轴 3、4 标「**未跑**」，**不算通过**，门禁 rc=1（除非显式 `--allow-partial`）。
- **成片期（有 `fin_frames`）**：四轴全跑；此时若仍有轴未跑，门禁直接不通过。

## 3. 预注册回退判据（**开工前定好，不许事后找理由**）

lite 档 = C2 执行方式 + §12–§14 三条新规范 + 四轴门禁。回退触发任一即退：

| # | 判据 | 动作 |
|---|---|---|
| 1 | `zorder` 抽出 **`[高]` 且 C0 为 0** | **立即修**（不用回退整档，这是可定点修的几何错）；修完覆盖率 ≥90% 才可交付 |
| 2 | `zorder` 可审覆盖率 **<90%** | 先补 `zorder_parts.json` / 改字面量；**覆盖率不达标时"0 命中"不可信**，不许拿它当通过证据 |
| 3 | `frame_metrics` **高** > C0 的高 **且** C0 为 0 | 回退该档，或只保留低风险部分 |
| 4 | `frame_metrics` **中** > C0 + 2 | 回退或只保留低风险部分 |
| 5 | `motion_check` 达标率 < C0 − 10 个百分点 | 回退 |
| 6 | 出现 C0 没有的**新缺陷类型**（遮挡 / 溢出 / 节拍错位） | 回退 |
| 7 | 都不触发 **且** 成本降 ≥40% | **通过** |

> 判据 6 是 EXP-01 里被违反过的一条：R先生 在 C2F 的 23.0s 处发现「后出现的 TLS 1.3 被先出现的论文卡压住」，命中的正是「C0 没有的新缺陷类型·遮挡」——按预注册判据 C2 当时应判**不通过**。
> 当时的失误不是"判据错"，是**判据没有对应的轴**：三根轴都看不到"元素互相遮挡"。**§12–§14 + 轴 2 就是补这个缺口。**

## 4. 覆盖矩阵（**交付前必填，逐条对着预注册判据标**）

写 QC 报告时，把预注册判据逐条过一遍，标出**这条由哪个轴覆盖 / 哪条完全没覆盖**：

| 预注册判据 | 覆盖它的轴 | 覆盖情况 |
|---|---|---|
| 帧覆盖 / 闪烁白名单 / 事实一致 / 分镜漂移 | 轴 1 | 全覆盖（机器） |
| 元素互相遮挡 / 层序倒置 / 压边 | 轴 2 | 覆盖，**但有盲区** → 看覆盖率 |
| 静止率 / 最长静止 | 轴 3 | 全覆盖（机器） |
| 主体尺度 / 光 / 碎屑 | 轴 4 | 覆盖，**"高"需人工裁定** |
| **字幕折行 / 文字被压暗但仍可辨** | — | **未覆盖 → 必须显式写"未验证"** |
| **柔光把邻近小元素洗淡（像素级，非几何相交）** | — | **未覆盖 → 必须显式写"未验证"** |
| **节奏/审美（哪一拍该慢、焦点是否唯一）** | — | **未覆盖 → 人工审片** |
| **音画同步 / 配音语速** | — | **未覆盖 → 人工审片** |

**规则：没有轴覆盖的判据，一律不许默认通过，必须写"未验证"。**

有一条规律值得记住并传给下一轮：**压缩会优先伤害那些只有人眼兜底的判据。** 被量化的指标被优化，没被量化的被牺牲——而压缩恰恰就是"减掉测量手段"的动作。

## 5. QC 报告结构（`qc/qc_<tag>.md`）

```markdown
# QC 报告 · <tag>（<日期>）

## 0. 门禁结论
- `lite_gate.py --tag <tag>` → **rc=<0/1>**
- 四轴读数表（照抄 qc/lite_gate_<tag>.md）

## 1. 空间冲突（轴 2）
- 层序命中：高 N / 中 M（逐条：谁压谁 / 重叠 px² / 帧号 / 几何来源）
- 可审覆盖率：P%（门槛 90%）
- 未解析清单：…（为空写"无"）

## 2. 结构一致（轴 1）
## 3. 动效密度（轴 3，成片期）
## 4. 画面构成（轴 4，逐条裁定，写明"接受/修"与理由）

## 5. 覆盖矩阵（照抄 §4，逐条标注）★必填
## 6. 已知盲区与未验证项 ★必填
## 7. 遗留项
```

**第 5、6 节不许省。** 一份不写"我没测什么"的 QC 报告，等于把风险转嫁给下游。

---

## 6. 人工审片清单（只留给机器真的做不到的）

交付前主会话自己看一遍，**只看这四件**（其余已被机器覆盖）：

1. **焦点唯一性**——每帧是不是只有一个视觉焦点（机器只看"最大物体"，看不出"两个都想当主角"）。
2. **节拍感**——该慢的地方是否够慢、该炸的地方是否炸得起来。
3. **音画同步**——解说与画面是否对得上（尤其是运镜起止）。
4. **字幕可读性**——有没有折行、有没有被压暗到勉强可辨。

## 7. 复用注意（血泪）

- **`frame_metrics` 要 1280×720**；走 `mc_one` 快路必须加 `--scale=1`。
- **`motion_check` 组级读数偏松**（低分辨率渲染），**成片 `fin_frames` 复测才是判据**。
- **`stills` 目录命名**：分档实验把图放 `stills_C2/` 时 `measure.py scan` 会漏计（用 `--stills-dir stills_C2`）。
- **抽帧目录必须证明来源**：凡"从渲染产物反推数字"的度量（`frame_metrics` / `motion_check --frames` / 逐帧差异），输入目录都算实验数据，先证明它属于哪一版。EXP-01 里曾有一份 `frame_metrics_C0.md` 是跑在混装残留帧的目录上，**把"低 13 条"错报成"低 14 条"**。→ **度量器再确定，也救不回喂错的数据。**
